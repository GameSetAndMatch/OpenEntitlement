# @openentitlement/core

Vendor-neutral product entitlements: feature checks, numeric limits, plans, overrides and grants.

```sh
npm install @openentitlement/core
```

Read the [SDK guide](https://github.com/open-entitlement/OpenEntitlement/blob/main/sdk-js/README.md) and [documentation](https://openentitlement.dev/docs/) for configuration and examples.
