# openentitlement-stripe

Stripe Entitlements adapter for OpenEntitlement.

```bash
pip install openentitlement-stripe
```

See the [Python SDK guide](https://github.com/open-entitlement/OpenEntitlement/blob/main/sdk-python/README.md) for configuration and examples, and the [documentation](https://openentitlement.dev/docs/) for the entitlement model.

This is an optional provider adapter, not a Tier variant. It depends on the core `openentitlement-sdk` distribution; Python imports remain `openentitlement`. See the [Python-first ACME case study](https://openentitlement.dev/docs/acme-workspace/) for Workspaces, Catalogs, Groups, Tags, Tiers and Organization/user scope.
