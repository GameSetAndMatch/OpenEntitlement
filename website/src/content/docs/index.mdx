<summary>How it works</summary>

Catalog defaults → Tier variant → Organization overrides. Boolean environment prerequisites can only restrict access. Try the controls above; this demo uses the console's Catalog, value editor and resolver, with sample data held in your browser tab.

OpenEntitlement is an open-source model, protocol and self-hostable service. Keep billing, roles and usage in your existing tools. The console is a preview and OEREP v1 is a draft.
