<h2 id="ask">One question from your application.</h2>

<p>The same contract in Python and TypeScript, against your own service or an embedded provider.</p>

```python
from openentitlement import Catalog, FixedProvider, create_client
from openentitlement import feature, integer

catalog = Catalog([feature("seats", "Seats", [integer("seat_max")])])
client = create_client(FixedProvider(catalog, {"seat_max": 40}), catalog)
client.get_limit("seat_max", {"organizationId": "globex"})  # 40
```
